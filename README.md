# 雷证 · MineProof

> **[English](README_EN.md)**

基于边界双重验证的自动标雷扫雷。不猜测，只证明。

## 玩法说明

1. 点击任意格开始（首点安全）。
2. 翻开数字后，系统自动在边界寻找可双重验证的雷点并标记。
3. 双重验证 = 至少两个数字各自独立推出同一候选格为雷，且局部约束枚举所有合法解均为雷。
4. 连续自动标记会触发加速——演出越来越快，12 秒内无上限递增。
5. 手动标旗仅作记录，不参与自动推理。

## 难度

| 难度 | 棋盘 | 雷数 |
|------|------|------|
| 入门 | 9×9  | 10   |
| 标准 | 12×14 | 28   |
| 进阶 | 16×18 | 54   |

## 特性

- **双重验证自动标雷**：不靠概率，每一步都有证明。
- **加速演出**：连续标记触发速度斜坡，越打越快。
- **音效系统**：每个数字对应音阶，标记时有和弦反馈。
- **纯前端**：无依赖，打开 `index.html` 即玩。

## 快速开始

```bash
git clone <仓库地址>
cd MineProof
# 直接用浏览器打开
open index.html      # macOS
start index.html     # Windows
xdg-open index.html  # Linux
```
